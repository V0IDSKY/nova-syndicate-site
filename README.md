# NØVA SYNDICATE

Premium cybersecurity education and research archive for operational knowledge, defensive practice, and structured learning.

## Included sections

- Research archive and topic database
- Practical code lab with copyable examples
- Interactive browser-based educational simulations
- Defensive cybersecurity content across networking, web security, crypto, forensics, privacy, architecture, and history

## Notes

This project is built as a static Cloudflare-compatible HTML page and preserves the existing brand direction: obsidian black, deep violet, electric purple, metallic silver, and premium research styling.

## Local preview

Open `index.html` in a web browser, or serve the directory locally with a simple static host such as:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
